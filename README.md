
## Data Skew Analysis and Partition Balancing

To investigate data distribution in the batch-processing pipeline, we performed a skew analysis on the actual Silver dataset generated by AirStream.

### Dataset
- Source: `data/processed/silver/openaq_measurements`
- Total records analyzed: 30,415,294
- Number of monitoring stations: 75

### Original Partition Distribution

The original Spark DataFrame contained 74 partitions with a highly uneven record distribution.

- Minimum partition size: 36 records
- Maximum partition size: 2,091,848 records
- Average partition size: approximately 411,017 records
- Coefficient of variation: 1.3411
- Maximum-to-minimum partition-size ratio: approximately 58,106.89

This demonstrated significant imbalance in the original Spark partition distribution.

### Partition Balancing Using Repartitioning

We applied Spark's `repartition(8)` operation to redistribute the Silver dataset across 8 partitions.

After repartitioning:
- Total records preserved: 30,415,294
- Minimum partition size: 3,801,906 records
- Maximum partition size: 3,801,916 records
- Average partition size: approximately 3,801,912 records
- Coefficient of variation: approximately 0.0000 (rounded)

The experiment confirmed that all records were preserved and the resulting partition sizes were nearly equal.

### Implementation

The experiment is implemented separately in:

`scripts/processing/08_skew_analysis.py`

The comparison results are saved in:

- `reports/skew_analysis/partition_comparison.csv`
- `reports/skew_analysis/skew_summary.txt`

### Conclusion and Limitation

The experiment demonstrates partition balancing through repartitioning on AirStream's actual Silver dataset. It is an additional analysis and optimization experiment; it does not currently modify the main batch-processing pipeline or existing Gold and AQI outputs.

The experiment measures partition balance, not processing-speed improvement. A controlled before-and-after performance benchmark would be required to establish whether repartitioning improves execution time.
